# إرسال محلي عبر الشبكة

تطبيق Android Native Java لإرسال واستقبال الملفات عبر الشبكة المحلية Wi-Fi.

## لماذا Java وليس Flutter؟
لأن المطلوب دعم Android 4.4، لذلك تم ضبط:

- `minSdk 19`
- Java Native
- بدون Flutter
- بدون مكتبات خارجية ثقيلة

## طريقة الاستخدام

### إرسال من الهاتف إلى الكمبيوتر
1. شغّل أداة الكمبيوتر لاحقًا على المنفذ `5050`.
2. اكتب IP الكمبيوتر داخل التطبيق.
3. اضغط: `اختيار ملف وإرساله للكمبيوتر`.

### استقبال على الهاتف
1. اضغط: `تشغيل استقبال الملفات على الهاتف`.
2. سيظهر عنوان الهاتف مثل:
   `http://192.168.1.10:5051/upload`
3. أرسل الملف لهذا العنوان من أداة ويندوز.
4. يحفظ التطبيق الملف في مجلد Download.

## APK
بعد نجاح GitHub Actions سيظهر الملف هنا:

`apk/send-via-local-net.apk`
