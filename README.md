# نقل محلي Pro — SendViaLocalNet

منظومة محلية لإرسال واستقبال الملفات بين **Windows وAndroid وiPhone/iPad** داخل شبكة Wi‑Fi، دون Cloud ودون رفع الملفات إلى الإنترنت.

## Android 2.1.0

التطبيق Native Java ويدعم **Android 4.4 (API 19) فما فوق**.

### الواجهة المبسطة

الواجهة الرئيسية تعمل بثلاث خطوات واضحة:

1. اضغط **بحث عن الأجهزة الآن**.
2. حدد جهازًا أو عدة أجهزة واختر الملفات.
3. اضغط **إرسال الآن**.

الإعدادات اليدوية والسجل موجودان داخل قسم **الإعدادات المتقدمة**، كما بقيت الواجهة السابقة متاحة من زر **الوضع المتقدم القديم**.

### اكتشاف الأجهزة

يستخدم التطبيق طريقتين معًا لتحسين موثوقية البحث:

- اكتشاف سريع عبر UDP Broadcast على المنفذ `5052`.
- فحص HTTP احتياطي للشبكة على المنفذ `5051`.

يظهر بجانب كل جهاز إحدى الحالتين:

- **متصل الآن**: الجهاز ظهر في آخر عملية بحث.
- **محفوظ وغير ظاهر**: الجهاز محفوظ لكنه غير متصل أو لم يستجب.

برنامج Windows يعلن عن نفسه تلقائيًا، كما تستطيع تطبيقات Android اكتشاف بعضها عندما تكون مفتوحة وعلى شبكة Wi‑Fi نفسها.

### مزايا Android

- حفظ عدة أجهزة بعناوين IP وأسماء اختيارية.
- تحديد عدة أجهزة وإرسال عدة ملفات إليها.
- استقبال تلقائي على المنفذ `5051`.
- Streaming للملفات الكبيرة دون تحميل الملف كاملًا في الذاكرة.
- حفظ الملفات في:

```text
Download/SendViaLocalNet
```

## Windows

برنامج Desktop مستقل يثبت مثل أي برنامج عادي، ولا يحتاج إلى Python أو PowerShell بعد تثبيته.

- تشغيل الاستقبال تلقائيًا.
- ملف تثبيت مع خيار إنشاء اختصار على سطح المكتب.
- إعلان تلقائي لتطبيق Android عبر UDP.
- دفتر أجهزة محفوظة.
- بحث تلقائي عن أجهزة Android.
- إرسال إلى عدة أجهزة مباشرة.
- استقبال ملفات Android وiPhone.
- عرض رابط وQR لفتح نسخة الهاتف.
- حفظ الملفات في:

```text
Downloads/SendViaLocalNet
```

## iPhone وiPad

نسخة Web App تعمل من Safari عبر برنامج Windows المحلي:

1. شغّل برنامج Windows.
2. امسح رمز QR الظاهر أو افتح الرابط المحلي.
3. من قائمة المشاركة في Safari اختر **إضافة إلى الشاشة الرئيسية**.
4. تظهر الأداة بأيقونة وتفتح كواجهة مستقلة.

يمكن للآيفون إرسال الملفات إلى Windows واستقبالها منه والإرسال المباشر إلى Android المحفوظ بالـIP. يلزم بقاء برنامج Windows مفتوحًا ليعمل مركزًا محليًا للآيفون.

## بروتوكول النقل

### نقل الملفات

```http
POST /upload
Content-Type: application/octet-stream
X-File-Name: encoded-file-name
X-File-Size: file-size
```

المنفذ: `5051`.

### اكتشاف الأجهزة

```text
SVLN_DISCOVER|request-id
SVLN_DEVICE|device-name|device-type|ip|5051
```

منفذ الاكتشاف: `5052/UDP`.

## البناء التلقائي

### Android APK

```text
apk/send-via-local-net.apk
```

### Windows Installer

```text
desktop/dist/SendViaLocalNet.exe
desktop/release/SendViaLocalNet-Setup.exe
```

ملف `Setup.exe` هو النسخة الموصى بها للمستخدم النهائي.

## هيكل المشروع

```text
app/                              تطبيق Android Native Java
desktop/app.py                    واجهة Windows والخادم المحلي
desktop/discovery_responder.py    إعلان Windows لتطبيق Android
desktop/web/                      واجهة iPhone وPWA
desktop/installer.iss             إعداد ملف تثبيت Windows
.github/workflows/                بناء Android وWindows تلقائيًا
```

## الخصوصية

- النقل يتم داخل الشبكة المحلية فقط.
- لا توجد قاعدة بيانات سحابية.
- لا تُرسل الملفات إلى خادم خارجي.
- الملفات المؤقتة الخاصة بصندوق iPhone تُحذف تلقائيًا بعد 24 ساعة.
